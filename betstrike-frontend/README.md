# BetstrikeFrontend

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.2.3.

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

## Backend connection setup

This frontend is configured to call the backend through `/api` in development.

1. Update `proxy.conf.json` and set the `target` to your backend URL (for example `http://localhost:5141`).
2. Make sure your backend exposes `GET /health` so the frontend connection check can verify it.
3. Run the frontend with `npm run start`.

For production builds, set `apiBaseUrl` in `src/environments/environment.production.ts` to your deployed backend URL.
